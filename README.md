**Bank Churners Analysis**

This project presents an Exploratory Data Analysis (EDA) of a bank's customer dataset to identify key factors contributing to customer churn. By analyzing various customer attributes, the goal is to uncover insights that can help in developing strategies to retain valuable customers.


📁 Repository Contents
BankChurners.csv: 
The primary dataset containing customer information, including demographics, account details, and churn status.

Data Analysis and Insights Extraction from Bank Churnrs.ipynb: 
Jupyter Notebook detailing the step-by-step EDA process, visualizations, and key findings.

Data Analysis and Insights Extraction from Bank Churners(report).pdf: 
A PDF report summarizing the analysis and insights derived from the dataset.

README.md: 
This file, providing an overview of the project.


📊 Key Insights
Demographic Factors: Analysis of how age, gender, and marital status influence churn rates.

Account Activity: Examination of account tenure, transaction counts, and credit limits to assess their impact on customer retention.

Service Usage: Evaluation of product holdings and service usage patterns to identify potential churn indicators.

Churn Correlation: Identification of features most strongly correlated with customer churn, aiding in predictive modeling.

📌 How to Use
Clone the Repository:
git clone https://github.com/AyushMagdum15/-Bank-Churners-Analysis.git

Navigate to the Project Directory:
cd -Bank-Churners-Analysis

Install Required Dependencies:
Ensure you have Python installed. Then, install the necessary libraries:
pip install pandas numpy matplotlib seaborn scikit-learn

Open the Jupyter Notebook:
jupyter notebook "Data Analysis and Insights Extraction from Bank Churnrs.ipynb"

Run the Analysis:
Execute the cells in the notebook sequentially to reproduce the analysis and visualizations.
